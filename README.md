# 🧮 Online Examination System (Java Swing)

A simple desktop-based **Online Exam Application** built using Java Swing.
Compressed and Original files are available !

## ✨ Features
- Login authentication (student / 123)
- 10 multiple choice questions
- Score calculation and result display
- Simple and lightweight desktop interface

## 🧠 How to Run
1. Download the project ZIP and extract it.
2. Open `src` folder in VS Code or any IDE.
3. Compile and run:
   ```bash
   javac *.java
   java LoginPage

4. Scroll down → click **Commit new file**
